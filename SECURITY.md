# Security Policy

## Supported Versions

Security fixes are handled on the default branch until the project starts publishing versioned releases.

## Reporting a Vulnerability

Please do not open public issues for suspected vulnerabilities.

Report security concerns by emailing the repository owner or by using GitHub private vulnerability reporting if it is enabled for this repository. Include:

- affected version or commit
- reproduction steps
- impact summary
- any relevant logs or sample files

Maintainers will acknowledge valid reports as soon as practical and coordinate a fix before public disclosure.
